# Agent008 — Android Writer Workspace

Agent008 — локальная писательская мастерская для работы с установленным приложением DeepSeek. Приложение не использует платный API и не требует API-ключа.

## Возможности
- Kotlin + Jetpack Compose.
- Локальные проекты и рукописи, хранящиеся на устройстве.
- Редактор рукописи с сохранением.
- Подготовка промпта с названием проекта и фрагментом текста.
- Копирование запроса в буфер обмена или передача через меню Android «Поделиться».
- Быстрое открытие приложения DeepSeek; если оно не установлено, открывается веб-чат.
- Поле для вставки ответа DeepSeek и добавление ответа в рукопись.
- Сборка debug APK через GitHub Actions.

## Работа без API-ключа
1. Создай или выбери проект.
2. Напиши задание и нажми «Подготовить запрос».
3. Нажми «Копировать», затем «Открыть DeepSeek» (или «Поделиться», если приложение доступно в списке).
4. Вставь запрос в DeepSeek и отправь его вручную.
5. Скопируй ответ и вставь в поле ответа Agent008.
6. Нажми «В рукопись», чтобы сохранить ответ в выбранном проекте.

Agent008 не управляет внутренним интерфейсом DeepSeek и не считывает ответы автоматически. Запросы и рукописи не отправляются из Agent008 в сеть; пользователь вручную переносит текст в DeepSeek.

## Сборка
1. Установи Android Studio и JDK 17.
2. Открой репозиторий как Gradle-проект.
3. Дождись синхронизации Gradle.
4. Выполни **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Через терминал с Android SDK и установленным Gradle: `gradle assembleDebug`.

## Ограничения версии 0.2.0
Это рабочий прототип писательской мастерской. Фонового агента, автоматического управления DeepSeek, web-поиска, импорта DOCX и автоматического извлечения канона пока нет.
