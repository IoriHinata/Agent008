# Agent008 — Android Writer Agent

Стартовое Android-приложение-помощник писателя с подключением к официальному DeepSeek API.

## Возможности
- Kotlin + Jetpack Compose.
- Чат с DeepSeek Chat Completions API.
- Локальные проекты и рукописи.
- Редактор текста с сохранением на устройстве.
- ИИ-помощь в написании и редактировании.
- API-ключ хранится через EncryptedSharedPreferences.
- GitHub Actions собирает debug APK.

## Сборка
1. Установи Android Studio и JDK 17.
2. Открой репозиторий как Gradle-проект.
3. Дождись синхронизации Gradle.
4. Выполни **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Через терминал с Android SDK: `gradle assembleDebug`.

## Настройка DeepSeek
1. Получи API-ключ в официальной консоли DeepSeek.
2. Открой Agent008 → Настройки.
3. Вставь ключ и сохрани.
4. Отправь тестовый запрос.

Ключ не хранится в исходном коде. Приложение отправляет текст запроса и выбранный контекст в DeepSeek API; не отправляй материалы, которые не готов передать внешнему сервису.
